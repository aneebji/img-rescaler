Exact-size PNGs. One crop per resolution.

A macOS desktop app for production batches. Frame each size like a profile-photo update, then export pixel-perfect PNGs into a dated folder.

View on GitHub HTTPS clone

Live crop

Drag to reframe, scroll to zoom. Each image and size keeps its own composition.

Exact output

Sharp extract + Lanczos3 resize. Always PNG at the width and height you set.

Batch runs

Every Rescale writes a new timestamped folder so previous jobs stay intact.
